# Evals

Evals de la extracción de documentos y del asistente. Llegan con las etapas "Carga con IA" y "Asistente".

El set de documentos de prueba y sus respuestas esperadas **no** entran al repo, porque son documentos reales. Los evals los leen de una ruta local o de un bucket privado. Los fixtures que sí viven acá son inventados.
